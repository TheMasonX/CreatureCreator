# Pages

MemorySmith-style wiki pages for CreatureCreator. The wiki engine serves
these pages at `/pages`. Pages are the durable knowledge store: architecture
overviews, guides, decisions, and workbench views.

## Layout

| Path | Contents |
| --- | --- |
| `workbench/tasks.md` | Human-readable task seed list and product history. |
| `Sources/` | Optional source attachments for page links. |

Until the service is verified, this directory holds only the workbench
template. Add project pages here once the wiki is live.
